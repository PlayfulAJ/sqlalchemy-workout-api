# SQLAlchemy Workout API

A Flask backend API for managing workouts and exercises using Flask, SQLAlchemy, and Marshmallow.

This project allows users to create, view, and delete workouts and exercises, as well as add exercises to workouts.

# Usage
This API allows users to:

- Create, view, and delete workouts
- Create, view, and delete exercises
- Add exercises to workouts
- View the relationships between workouts and exercises
